# Neon Reels (Demo)

A lightweight browser-based slot-style demo inspired by casino arcade experiences.

## Features

- 3-reel spin flow with symbol animation.
- Adjustable in-game credit bet.
- Local paytable with 3-of-a-kind rewards.
- Clearly marked as **no real-money gambling**.

## Run

Open `index.html` directly in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
